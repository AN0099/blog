# Projects

## Toothpaste Kit

[github.com/AN0099/toothpaste-kit](https://github.com/AN0099/toothpaste-kit)

A skill library, an agent relay protocol, and a set of mechanical gates for
running multi-agent work with a person in charge of it. MIT licensed, pre-alpha.
Each release is archived on Zenodo; the concept DOI
[10.5281/zenodo.22850481](https://doi.org/10.5281/zenodo.22850481) always
resolves to the newest version.
