## Bridle Works

The development blog of Bridle Works, published as
[AN0099](https://github.com/AN0099) and written by Aidan Naveja.

Bridle Works builds tools for running multi-agent work with a person in charge
of it. The work is judged on control fidelity rather than capability: state a
person can read, mistakes that are cheap to correct, and a halt that works when
it is needed.

The first project is [Toothpaste Kit](https://github.com/AN0099/toothpaste-kit),
a skill library, an agent relay protocol, and a set of mechanical gates. It is
pre-alpha and in daily use. See [Projects](/projects/) and [Now](/now/).
